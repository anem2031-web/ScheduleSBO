## بوابة الانتقال

لا يبدأ العمل على مرحلة جديدة حتى:

1. تصل المرحلة الحالية إلى 99%.
2. تنجح اختبارات TypeScript والبناء.
3. تنجح اختبارات الوحدة والتكامل.
4. يكتمل الاختبار اليدوي.
5. تغلق المشكلات الحرجة والعالية.
6. تحدث ملفات التوثيق.
7. يعتمد صاحب المشروع الانتقال.
