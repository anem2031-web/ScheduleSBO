## النتيجة

تم اختبار المسارات الأساسية في صفحات اليوم، العمال، الجدول الأسبوعي، العمل الإضافي، المراجعات والاعتمادات، والتهيئة باستخدام أدوار الإدمن، المشرف، والشؤون الإدارية. أُنشئت بيانات اختبار مؤقتة معزولة ثم حُذفت بعد انتهاء الاختبار.

## ما تم اختباره

| المجال | النتيجة |
|---|---|
| صفحة اليوم | تحميل العمال، البحث، الفلاتر، الاختصارات، واحتساب التأخير مع الزيادة |
| العمال | إنشاء عامل، التحقق من الحقول المطلوبة، الهاتف، التعديل، بطاقة العامل، المشرفون، ورصيد اليوم/الأسبوع/الشهر |
| الجدول الأسبوعي | البحث، فتح خلية، فترة تتجاوز منتصف الليل، الاستراحة، صافي الساعات، الحفظ، التنبيهات، وتصدير صورة مركز |
| العمل الإضافي | الزيادة المخططة والفعلية، الساعات والدقائق، مركز التكلفة، سجل القرار، قبول المشرف، رفض واعتماد الشؤون، وإعادة الاعتماد |
| المراجعات والاعتمادات | رفض إجازة بسبب إلزام السبب، عرض سبب الرفض، الإجازة السنوية الطويلة، المرضية، والاستئذان المعتمد |
| التهيئة | مراكز التكلفة، المواقع، الأقسام، المسميات، ربط الموقع بالقسم، وقائمة المشرفين |
| الصلاحيات | عزل نطاق المشرف، صلاحيات الشؤون الإدارية الكاملة، وحساب شؤون إدارية بلا اعتماد نهائي |
| طبقة الخدمة | حالات التداخل، الاعتماد المزدوج، حدود الاعتماد، تصحيح الحضور، ونطاق الوصول |

## المشاكل التي أُصلحت

1. كان عنوان عداد العمال يعرض «إجمالي العمال» رغم وجود بحث؛ أصبح يوضح أنه عدد نتائج البحث.
2. كانت خيارات المشرف تعرض أقواسًا فارغة عند عدم وجود بريد؛ أزيلت الأقواس الفارغة.
3. بعض أيقونات التهيئة لم تكن تحمل اسمًا مفهومًا لقارئات الشاشة؛ أضيفت لها أسماء عربية واضحة.
4. صورة الجدول الأسبوعي لم تكن تعرض الاستئذان المعتمد؛ أصبحت تعرضه داخل الفترة المناسبة مع قصه عند حدود الفترة.
5. صفحة اليوم لم تخصم الاستئذان المعفى من الساعات المطلوبة؛ تم تصحيح الحساب.
6. عداد التأخير كان يفقد التأخير عندما تكون الحالة مرتبطة بوقت إضافي؛ أصبح التأخير محسوبًا من وقت البصمة الفعلي.
7. خلية الجدول كانت تعرض الرصيد الاسمي بدل الرصيد بعد الاستئذان؛ تم ربطها بالرصيد المعدل.
